# Project Statement

## Project Title
Movie Booking System

## Problem Statement
Booking movie tickets manually can be slow and can create mistakes in seat allocation. A small digital system can store movie details, show timings, seat availability and bookings in one place.

## Scope
The project covers user registration/login, movie browsing, show management, seat selection, ticket booking, cancellation and simple booking/revenue reporting. It is a local academic project using SQLite; it does not include real payment gateways or online deployment.

## Target Users
1. Customers who want to browse movies and book/cancel tickets.
2. Cinema administrators who manage movies/shows and view booking reports.

## High-Level Features
- Account creation and login
- Movie search and listing
- Movie/show administration
- Seat availability checking
- Multi-seat ticket booking
- Booking history and cancellation
- Admin reports
- Validation, logging and tests
